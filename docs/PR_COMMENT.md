## 用途 / Purpose
**JA:** PacketScope で取得したプロファイルから、実ネットワークカメラの**映像ストリームを再現**するアプリ。320×170 画面でカメラプロファイル JSON を選ぶと、内蔵カメラを GStreamer（Pi ではハードウェア H.264）でその形式に符号化し、実カメラと同じ方式で配信: マルチキャスト RTP（H.264/MPEG2-TS・MPEG-2・国交省 MPEG2-TTS/PT103・RTP-JPEG）、RTSP サーバ、HTTP Motion-JPEG サーバ。配信モード・宛先・パケット/バイト数をライブ表示。**映像のみ（PTZF カメラ制御なし）**。PacketScope と対で「観測→再現」の往復を成す。
**EN:** Regenerates a real network camera's **video stream** from a profile captured by PacketScope. Pick a camera-profile JSON on the 320×170 screen; it encodes the built-in camera to that exact format via GStreamer (hardware H.264 on the Pi) and delivers it as the real camera did: multicast RTP (H.264/MPEG2-TS, MPEG-2, MLIT MPEG2-TTS/PT103, RTP-JPEG), an RTSP server, or an HTTP Motion-JPEG server — with live delivery-mode / destination / packet & byte counters. **Video only (no PTZF camera control).** Pairs with PacketScope as the observe→reproduce round-trip.

## 既知の制限・権限 / Known limitations & permissions
**JA:** ① **実機未検証**（上記）。② **同梱プロファイルが少数**（合成＋匿名化した実キャプチャ由来）で任意ベンダ全形式は網羅せず。③ **camera + network 権限**: 再現中は内蔵カメラ映像を LAN へ配信（設計上のデータ送出）— `app-builder.json` の `permissions`/`risk_flags` に明記。
**EN:** ① **Not hardware-verified** (above). ② **Few bundled profiles** (synthetic + anonymized real-derived); not exhaustive vendor coverage. ③ **camera + network permissions**: while reproducing, the built-in camera's encoded video is streamed over the LAN by design — declared in `permissions`/`risk_flags`.
